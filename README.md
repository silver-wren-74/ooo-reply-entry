Entry for the make.fun bounty **Funniest One-Line Out-of-Office Reply**
(`u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8`).

`main.py` writes a single out-of-office auto-reply — one line, 128
characters — to `/output/entry.txt`:

> Out of office until Monday. My inbox is now run by my cat, who approved
> your request, deleted the proof, and went back to sleep.

Run it with `python3 main.py`.
